# どきどき☆メルトダウン

かわいく発電。油断でドカン。円形炉の連鎖反応を、制御棒・冷却・燃料補給で維持するアーケードゲームです。リポジトリ名はMeltdownRacer、ゲーム表示名は「どきどき☆メルトダウン」。実在の原子炉の運転条件を再現しません。

## ローカルで遊ぶ

Node.js 22.12以上推奨。リポジトリのフォルダーで実行します。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173 を開いて開始。初回の依存関係インストール後はインターネット接続不要。外部フォント・画像・音源・APIへの通信はありません。サーバーは遊んでいる間起動しておいてください。

```sh
npm test
npm run build
npm run preview # http://127.0.0.1:4173
npx tsx scripts/balance.ts
npx tsx scripts/endless-balance.ts
```

本番のdist/は静的HTTPサーバーで配信できます。HTMLの直接ダブルクリックでは起動できません。オンライン公開は未設定。

## v0.3 の遊び方

- **制御棒**：真上から見た炉に64個の吸収点を均等配置。0〜100%スライダーで、上下左右の対称な4本組を挿入します。黒い丸＋ピンクの縁が挿入中、薄い丸が未挿入です。例：25%=16本、50%=32本。途中の割合は4本単位へ丸め、実際の本数も表示します。以前の上から差す4本の方式を置き換えました。A / Dでも操作できます。
- **冷却水**：流量を増やすと冷却・水位回復が強くなり、ポンプ消費電力も増加。W / Sでも操作できます。
- **燃料補給**：炉または区画ボタンで区画を選び、灰色の使用済み燃料を交換。初期8回、12秒間隔。Rでも実行可能。
- **早送り**：▶ボタンで1→2→4→8倍。炉・得点・補給待ち時間は同じ速度で進みます。曲のテンポは変わりません。
- **一時停止**：ボタンまたはSpace。タブ非表示時は自動停止。記録・遊び方を開いても停止し、明示操作で再開します。
- **フィーバー**：反応1.8〜15/秒、正味出力12以上を5秒維持。安定倍率最大3倍、十分な反応と出力を伴う高温運転で最大2倍、合計最大6倍。判定の揺れには2秒の猶予があります。
- **ゲームオーバー**：炉温105または圧力100を超えると危険度が増加し、100%で設備破裂。開始20秒以降、反応0.7未満かつ炉温30未満が10秒続くと低温停止。

初期設定は制御棒50%・流量42%。反応を抑えても蓄積熱はすぐには消えません。水流・水位・蒸気・タービンも計器に連動します。PU / EUはゲーム独自の単位です。

## モードとショップ

| モード      | 内容                                                       |
| ----------- | ---------------------------------------------------------- |
| 生存        | 初期8回の補給を使って失敗まで運転                          |
| 日替わり5分 | 日本時間の日付で共通シード。300秒でクリアするローカル練習  |
| ∞ショップ   | 終了時間なし。発電で燃料補給を何度でも買い足せるエンドレス |

ショップでは**実際に発電した1 EU = 1,000⚡**を獲得し、**120⚡で区画補給券を1枚**購入します。購入回数上限・価格上昇はありません。倍率は買い物用電力を増やしません。残高は購入で減りますが、累計発電量とスコアは減りません。購入後に区画を選び、補給ボタンで使ってください。12秒クールダウンは購入しても解除されません。

エンドレスでも過熱・低温停止はゲームオーバーです。運転と購入を続けられる限り、時間や補給回数による強制終了はありません。残高と購入券は1プレイ限りです。

## デザインと音楽

丸いポップな日本語ロゴとキャンディ配色、虹色の枠・星・発光フィーバーを採用。演出OFFで強い動きを抑えられ、OSの動きを減らす設定にも対応します。

Web Audioでオリジナルの曲を合成。通常112 BPM、フィーバー172 BPMの高速チップチューン、終了後66 BPMの短調。メロディー・ベース・和音・打楽器を組み合わせています。開始操作後に有効化し、ミュート可能。爆発音の後に結果曲が流れます。外部音源・ライセンス不明の素材は使いません。

PCとスマホで配置を変え、炉・計器・ショップを同じ画面に配置。非常に小さい画面のタイトル説明は内部スクロールできます。

## 構成と記録

| ファイル          | 役割                                                    |
| ----------------- | ------------------------------------------------------- |
| src/config.ts     | 数値調整、ゲーム版・設定版                              |
| src/simulation.ts | DOM非依存の60Hz固定tick、シード乱数、ショップ、操作履歴 |
| src/rods.ts       | 対称な制御棒配置・挿入順序                              |
| src/rendering.ts  | 炉内のCanvas描画                                        |
| src/effects.ts    | 水流・タービン・虹色フィーバー・爆発                    |
| src/audio.ts      | 実時間クロックで合成する3種のBGM                        |
| src/main.ts       | UI、操作、時間積算、結果画面                            |
| src/ranking.ts    | ローカル記録と将来の接続インターフェース                |

燃料は約380粒。空間ハッシュと線分判定で燃料との衝突を計算。制御棒も移動線分から吸収判定し、吸収済み中性子は反応しません。中性子の寿命は7秒、炉外へ出た場合と全端末共通上限600個を超えた場合は逸出として扱います。

フレーム遅延は最大100msまで取り込み、過度な追いつきを防ぎます。非常に重い端末では実時間よりゲーム時間が遅れます。描画がゲーム乱数・得点を変更することはありません。

ゲーム版0.3.0・設定版3。ローカル記録はゲーム版・モードを分け、日替わりは日付別に表示します。旧版データは保持します。結果からシード・版・入力tick・総tick数を含むJSONを保存でき、playReplay(replay, totalTicks)で購入も含め再計算できます。旧版のリプレイは拒否します。UIでのリプレイ読込・鑑賞は未実装。

オンラインランキング、認証、run ID、入力履歴のサーバー検証、DB、クラウド公開は後続作業。ローカル記録は改変可能です。異なるブラウザエンジン間の厳密な再現性も公開前の検証対象です。

具体的な試験結果は[VALIDATION.md](VALIDATION.md)を参照してください。
