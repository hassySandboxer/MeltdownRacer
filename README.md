# MeltdownRacer

**臨界を、乗りこなせ。** 円形炉で連鎖反応を育て、制御棒・冷却水・燃料補給を使って発電スコアを競うブラウザ向けアーケードゲーム。実在の原子炉を再現せず、架空のゲーム指標を使用します。

## ローカルで遊ぶ

Node.js 22.12以上を推奨。リポジトリのフォルダーで実行してください。

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開き「運転を開始」。初回の依存関係インストール後はインターネット接続不要です。外部フォント・画像・音源・APIへの通信はありません。ローカルサーバーは終了まで動かしておいてください。

```sh
npm test         # シミュレーションの回帰テスト
npm run build   # 型検査 + dist/ へ本番ビルド
npm run preview # 本番ビルドを http://127.0.0.1:4173 で確認
npx tsx scripts/balance.ts # 50シードの放置試験 + 5シードの5分運転
```

`dist/` は静的HTTPサーバーで配信できます。ES Modulesを使用するためHTMLの直接ダブルクリックでは起動できません。クラウド公開は未設定です。

## 遊び方

- **制御棒**：挿入で中性子を吸収し、反応を抑制。4本を独立操作できます。「4本同時」ONなら操作した棒の深さに全棒を揃えます。OFFなら1〜4キーで選んだ棒をA / Dで操作可能。
- **冷却水**：流量を上げると炉温低下・水位回復。ポンプ消費電力も増加。W / S でも操作可能。
- **補給**：炉または区画ボタンで区画を選択し、使用済み燃料を交換。8回まで、12秒間隔。Rでも実行可能。
- **一時停止**：ボタンまたはSpace。タブ非表示時にも自動停止し、明示操作で再開。スライダーにフォーカス中は標準の矢印操作を使えます。
- **フィーバー**：反応1.8〜15 / 秒、正味出力12以上を5秒維持。安定倍率は最大3倍、十分な反応と出力を伴う高温運転で最大2倍、合計最大6倍。判定の揺れに2秒の猶予。
- **終了**：炉温105または圧力100超で危険度が増加し、100%で設備破裂。開始20秒以降、反応0.7未満かつ炉温30未満が10秒続くと低温停止。

初期設定は制御棒60%・流量42%。炉温が上がりすぎたら制御棒と流量を増やし、低温時は反対に調整。灰色になった燃料を区画補給してください。

**生存モード**は失敗するまで継続。**日替わり5分**は日本時間の日付から共通シードを作るローカル練習版。300秒到達でクリアです。モードを選び直す場合は左上ロゴでタイトルに戻れます（進行中の運転は破棄）。Web Audioの合成BGMは開始操作後に有効化。ミュート可能です。

正味出力の正の部分を積分した発電量（EU）と、倍率を適用したスコアを分けて記録します。PU / EUはゲーム独自の単位です。結果には終了理由・累計発電・最長連続フィーバー・運転時間を表示します。

## 構成

| ファイル                   | 役割                                                          |
| -------------------------- | ------------------------------------------------------------- |
| `src/config.ts`            | ゲーム定数・ゲーム版・設定版                                  |
| `src/simulation.ts`        | DOM非依存、60Hz固定tick、シード乱数、操作記録・リプレイ再計算 |
| `src/rendering.ts`         | Canvas描画。ゲーム乱数や得点を変更しない                      |
| `src/main.ts`              | UI・入力・フレーム積算・停止・結果                            |
| `src/ranking.ts`           | ローカル記録と将来のRankingClient接続箇所                     |
| `src/audio.ts`             | 合成BGM・フィーバーレイヤー・警告音                           |
| `tests/simulation.test.ts` | 決定論・衝突・得点・操作・終了のテスト                        |

燃料は約380粒（境界付近の個数はシード依存）。衝突は空間ハッシュと線分判定。中性子は7秒の寿命または炉外への逸出で消滅します。**全端末共通上限600個**を超える中性子も逸出として計上します。描画品質によって反応やスコアを変更しません。

フレーム遅延は最大100msまで取り込み、無制限の追いつき計算を防ぎます。極端に重い端末では実時間より運転時間が遅れます。日替わりは一時停止可能な練習版で、オンライン競技の公平性は保証していません。

## 記録と今後の拡張

得点上位50件をlocalStorageに保存。表示はモード別、日替わりは当日・ゲーム版別の上位5件。保存できない環境でもゲームは続行し、結果で未保存を知らせます。

結果からJSONリプレイを保存できます。シード・ゲーム版・設定版・入力tick・総tick数を含み、`playReplay(replay, totalTicks)`で再計算可能。UIでの読込・鑑賞は未実装です。同一JS数値モデルでの再現性を検証していますが、異種エンジン間の厳密一致は公開前の追加検証対象です。

オンラインランキング、認証、run ID、入力履歴のサーバー検証、DB、クラウド公開は今後の作業です。ローカル記録は改変可能で、オンラインの検証済み記録としては扱いません。
