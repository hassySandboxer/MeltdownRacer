# Bundled fonts

M PLUS Rounded 1c Regular and ExtraBold, from https://github.com/google/fonts/tree/main/ofl/mplusrounded1c . Copyright 2016 The Rounded M+ Project Authors.

Unmodified TTF files are served locally so Japanese text, logos and numbers use the same typeface on Windows, Android, macOS and iOS without installed fonts or a third-party font request. OS rasterization can still differ slightly.
